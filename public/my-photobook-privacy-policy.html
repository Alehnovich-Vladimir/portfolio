Privacy Policy for My PhotoBook

Last updated: July 17, 2026

My PhotoBook is a photo album and printable photobook app. The app is designed to work locally on the user's device.

Data the app uses

My PhotoBook may use:

  • photos selected by the user from the device photo library;
  • photo captions, album titles, album descriptions, album colors, crop settings, and photo order;
  • optional photo metadata, such as photo date and embedded photo location coordinates, when the user creates smart albums or uses features that depend on photo metadata;
  • media-location metadata access on Android when needed to read location coordinates embedded in selected photos;
  • generated PDF files created by the user.

How data is stored

Album data and imported photo copies are stored locally in the app's private storage on the user's device. The app does not require an account and does not use its own backend server.

Sharing and export

The app can generate PDF files and pass them to Android's system share/open dialogs when the user chooses to preview, share, or export a photobook. After that, handling is controlled by the app or service selected by the user.

Data collection and third parties

My PhotoBook does not include advertising SDKs or analytics SDKs. The app developer does not collect, sell, or share user photos or album content through a developer-operated server.

Platform services and user-selected destination apps may process data when the user grants permissions, opens a PDF, or shares a file.

Permissions and location

The app may request photo library access so the user can select photos for albums. In smart album mode, it may request access to photo metadata, including embedded photo location metadata, to support automatic dates and place names.

On Android, the app may request media-location metadata access to read GPS coordinates already embedded in selected photos. The app does not request live device location, does not use background location, and does not continuously track the user's current location.

Deleting data

The user can delete albums inside the app. The user can also remove app data by uninstalling the app or clearing app storage through Android system settings.

Политика конфиденциальности My PhotoBook

Последнее обновление: 17 июля 2026 года

Русский

My PhotoBook — приложение для создания фотоальбомов и PDF-фотокниг для печати. Приложение рассчитано на локальную работу на устройстве пользователя.

Какие данные использует приложение

My PhotoBook может использовать:

  • фотографии, выбранные пользователем из библиотеки фотографий устройства;
  • подписи к фотографиям, названия альбомов, описания альбомов, цвета альбомов, настройки кадрирования и порядок фотографий;
  • необязательные метаданные фотографий, например дату снимка и встроенные координаты места съёмки, если пользователь создаёт умные альбомы или использует функции, зависящие от метаданных фотографий;
  • доступ к геометаданным медиафайлов на Android, когда он нужен для чтения координат, встроенных в выбранные фотографии;
  • PDF-файлы, созданные пользователем.

Как хранятся данные

Данные альбомов и импортированные копии фотографий хранятся локально в приватном хранилище приложения на устройстве пользователя. Приложение не требует аккаунта и не использует собственный сервер.

Отправка и экспорт

Приложение может создавать PDF-файлы и передавать их в системные окна Android для предпросмотра, отправки или экспорта, когда пользователь сам выбирает такое действие. После этого обработка файла зависит от приложения или сервиса, выбранного пользователем.

Сбор данных и третьи стороны

My PhotoBook не содержит рекламных SDK и аналитических SDK. Разработчик приложения не собирает, не продаёт и не передаёт фотографии пользователя или содержимое альбомов через сервер разработчика.

Платформенные сервисы и выбранные пользователем приложения могут обрабатывать данные, когда пользователь выдаёт разрешения, открывает PDF или отправляет файл.

Разрешения и местоположение

Приложение может запрашивать доступ к библиотеке фотографий, чтобы пользователь мог выбрать фотографии для альбомов. В режиме умного альбома приложение также может запрашивать доступ к метаданным фотографий, включая встроенные данные о месте съёмки, для автоматических дат и названий мест.

На Android приложение может запрашивать доступ к геометаданным медиафайлов, чтобы прочитать GPS-координаты, уже встроенные в выбранные фотографии. Приложение не запрашивает текущее местоположение устройства, не использует фоновое местоположение и не отслеживает текущее местоположение пользователя.

Удаление данных

Пользователь может удалить альбомы внутри приложения. Также пользователь может удалить данные приложения, удалив приложение или очистив его хранилище в системных настройках Android.

Política de privacidad de My PhotoBook

Última actualización: 17 de julio de 2026

Español

My PhotoBook es una aplicación para crear álbumes de fotos y fotolibros PDF listos para imprimir. La aplicación está diseñada para funcionar localmente en el dispositivo del usuario.

Datos que usa la aplicación

My PhotoBook puede usar:

  • fotos seleccionadas por el usuario desde la biblioteca de fotos del dispositivo;
  • pies de foto, títulos de álbumes, descripciones de álbumes, colores de álbumes, ajustes de recorte y orden de las fotos;
  • metadatos opcionales de las fotos, como la fecha de la foto y las coordenadas de ubicación incrustadas, cuando el usuario crea álbumes inteligentes o utiliza funciones que dependen de los metadatos de las fotos;
  • acceso a metadatos de ubicación de medios en Android cuando sea necesario para leer coordenadas incrustadas en las fotos seleccionadas;
  • archivos PDF generados por el usuario.

Cómo se almacenan los datos

Los datos de los álbumes y las copias de las fotos importadas se almacenan localmente en el almacenamiento privado de la aplicación en el dispositivo del usuario. La aplicación no requiere una cuenta y no utiliza un servidor propio.

Compartir y exportar

La aplicación puede generar archivos PDF y pasarlos a los diálogos del sistema Android para vista previa, compartir o exportar cuando el usuario elige esa acción. Después de eso, el tratamiento del archivo depende de la aplicación o servicio seleccionado por el usuario.

Recopilación de datos y terceros

My PhotoBook no incluye SDK publicitarios ni SDK de analítica. El desarrollador de la aplicación no recopila, vende ni comparte las fotos del usuario ni el contenido de los álbumes a través de un servidor operado por el desarrollador.

Los servicios de la plataforma y las aplicaciones de destino seleccionadas por el usuario pueden procesar datos cuando el usuario concede permisos, abre un PDF o comparte un archivo.

Permisos y ubicación

La aplicación puede solicitar acceso a la biblioteca de fotos para que el usuario pueda seleccionar fotos para sus álbumes. En el modo de álbum inteligente, también puede solicitar acceso a metadatos de las fotos, incluidos los datos de ubicación incrustados, para admitir fechas y nombres de lugares automáticos.

En Android, la aplicación puede solicitar acceso a metadatos de ubicación de medios para leer coordenadas GPS ya incrustadas en las fotos seleccionadas. La aplicación no solicita la ubicación actual del dispositivo, no usa ubicación en segundo plano y no rastrea continuamente la ubicación actual del usuario.

Eliminar datos

El usuario puede eliminar álbumes dentro de la aplicación. También puede eliminar los datos de la aplicación desinstalándola o borrando su almacenamiento desde los ajustes del sistema Android.
